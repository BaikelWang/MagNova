# 为什么多性质评分使用相对不确定性

带隙的单位通常是 eV，居里温度的单位是 K。假设两项预测误差都是 3%：

```text
带隙：1.5 ± 0.045 eV
居里温度：500 ± 15 K
```

如果直接平均绝对误差：

```text
(0.045 + 15) / 2
```

温度项会因为数值尺度更大而完全主导评分。这不是模型更不确定，而是单位
和量纲不同。

当前筛选器先计算每项的相对不确定性：

```python
relative_uncertainty = uncertainty / abs(predicted_value)
```

再对无量纲结果求平均。这样 3% 的带隙误差和 3% 的居里温度误差具有同等
权重。

这仍然只是 MVP。真实项目还应考虑：

- 预测值接近零时的稳定尺度；
- 不同性质的重要性权重；
- 模型校准误差；
- Aleatoric 与 Epistemic uncertainty；
- Pareto 排序而不是强行压成单一分数。

面试中可以强调：

> 多目标材料筛选不能直接混合不同单位的绝对数值。我先将预测不确定性
> 转换成无量纲相对量，再参与综合评分，从而避免量纲和数值尺度造成的
> 虚假权重。
