# Notices

MagNova integrates with, but does not redistribute, upstream projects and model assets including MiniMind, MatterGen, and MatterSim. Users must obtain those projects and assets from their official sources and comply with their respective licenses and usage terms.

The `training/minimind` utilities expect a compatible MiniMind checkout. The `integrations/mattergen` workflow expects a compatible MatterGen checkout and separately downloaded checkpoints/reference data.

No SACGT implementation or model asset is included in this public repository.

The October 2026 showcase adds original MagNova diagrams and selected historical application screenshots, without changing the existing public code baseline. These additions do not grant a new open-source license for MagNova's original code or visuals.

Literature excerpts visible in the retrieval screenshot are attributed to Zeni et al., *A generative model for inorganic materials design*, Nature 639, 624–632 (2025), https://doi.org/10.1038/s41586-025-08628-5, under CC BY 4.0. This attribution applies to the paper excerpts, not to the surrounding MagNova interface. See docs/assets/README.md.
