# Security policy

Do not open a public issue containing credentials, private service URLs, unpublished datasets, model weights, or sensitive scientific artifacts.

If you discover a security problem, contact the repository owner privately through the contact information on the GitHub profile. Include a minimal reproduction and avoid attaching secrets or proprietary data.

The demo UI is a research prototype. Its session identifier is not production authentication, and the SQLite store is intended for a trusted single-node environment.
